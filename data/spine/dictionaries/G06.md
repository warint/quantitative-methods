## Traps in this file

> Read these before you model. Each one has cost somebody a week.

- **`ai_use_any`** — NOT AVAILABLE BEFORE 2021 — structurally absent, not missing at random.
- **`cloud_use`** — Available from 2014 — a longer panel than the AI columns.
- **`n_enterprises`** — Use as a weight. Unweighted means across size classes are misleading.
- **`flag`** — u = low reliability · c = confidential (value is NaN) · b = break in series · p = provisional. Dropping 'u' silently biases coverage toward large economies.
